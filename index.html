Lab Overview

SAIL(안전 자율·지능연구실)은 이동로봇·모바일로봇 등 자율이동체가 안전을 보장하면서 복잡한 환경에서 움직이도록 만드는 제어·계획 알고리즘을 연구합니다. 이론적으로 안전성을 증명할 수 있는 제어기와, 실제 로봇에서 동작하는 시스템을 함께 만듭니다.

핵심 도구는 모델예측제어(MPC), 제어 장벽 함수(CBF), 도달가능성 해석(Reachability Analysis), 그리고 학습·데이터 기반 모델링입니다. 실내·실외 환경에서의 자율주행, 충돌회피, 로봇 제어까지 실험을 통해 검증합니다.

SAIL에서 무엇을 하나요?

  • 안전 궤적 계획 및 제어 알고리즘 설계
  • MPC / CBF / Reachability 기반 충돌회피
  • 학습 기반 동역학 모델링 및 제어
  • 필드 실험 및 국제 학술 발표

이런 학생을 찾습니다

  • 제어·로봇·자율주행에 관심이 있는 학부생·대학원생
  • 수학/동역학 기초를 실제 시스템에 적용하고 싶은 학생
  • 프로그래밍(Python, C++, MATLAB)으로 실험을 해보고 싶은 학생

Research

Core

Multi-modal Obstacle Avoidance Trajectory Planning & Control

회전원 CBF로 추종·회피·접안 모드를 안전하게 고르는 멀티모달 계획

View Details

비홀로노믹 이동체의 회전반경을 제약으로 넣고, 하나의 궤적이 아니라 여러 거동 후보 중에서 안전한 모드를 고릅니다.

Core

Learning-based Planning & Control

딥러닝 기반 MPC와 LLM 항법

View Details

학습으로 동역학을 맞추고, 포항 운하 자율운항과 LLM 기반 선박 질의응답(MARQA)으로 계획·제어를 연결합니다.

Core

Robust Model Predictive Control

Tube-MPC, 접안, 드론, Koopman 모델링

View Details

외란과 모델 오차 아래에서도 안전 영역을 지키는 cascade tube-MPC, L1 적응, Koopman 기반 데이터 구동 제어를 다룹니다.

영상은 구글 사이트 자료를 옮기는 대로 넣겠습니다.
Core

Control Barrier Function (CBF)

접안용 exact-geometry MPC-CBF, 회전원 CBF, COLREGs 충돌회피

View Details

좌·우 회전원으로 회피 방향과 선회 능력을 같이 넣고, COLREGs를 지키면서 QP로 빠르게 풉니다.

Core

Mobile Robots

AGV 동적 장애물 회피와 배송 로봇 보행자 회피

View Details

혼잡한 보행자 공간에서 LEMO 등 모바일 로봇이 사람을 피해 가는 궤적 계획을 연구합니다.

영상은 구글 사이트 자료를 옮기는 대로 넣겠습니다.
Core

Marine Vehicles

ASV 충돌회피와 포항 운하 자율운항

View Details

실선 ASV와 크루즈 보트에서 인지–계획–제어를 검증하고, 운하·연안 데이터셋을 같이 공개합니다.

Core

Multi-agent Control

자율이동체 formation tracking

View Details

베어링 기반 formation tracking으로 여러 이동체가 상대 위치를 유지하며 움직이게 합니다. Co-work: Dr. Quoc Van Tran (HUST).

영상은 구글 사이트 자료를 옮기는 대로 넣겠습니다.
Plan

Physical AI

실로봇에서 학습과 안전 제어를 붙이는 다음 방향

View Details

Physical AI는 시뮬레이터가 아니라 LEMO·해양 플랫폼이 물리 세계와 직접 상호작용하며 배우고 움직이는 것을 목표로 합니다. CBF·reachability 같은 안전 제약을 학습 정책에 넣어, 현장에서 실패해도 안전한 거동을 남기려 합니다.
