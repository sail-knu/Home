## Local preview

`index.html`을 브라우저로 열거나, 폴더에서 정적 서버를 켜면 됩니다.

```bash
python -m http.server 8080
```

## GitHub Pages

Repository Settings → Pages → **Deploy from a branch** → `main` / `/ (root)`.

반영까지 1–2분 정도 걸립니다. 주소는 `https://sail-knu.github.io/Home/` 입니다.
