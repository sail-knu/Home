선형 MPC는 QP입니다. 상태를 예측식으로 밀어 넣으면 입력 수열에 대한 이차 계획이 됩니다. 여기서는 CVXGEN으로 C/MATLAB 솔버를 만드는 절차를 적습니다.

CVXGEN으로 LMPC

  1. cvxgen.com에서 계정을 만듭니다.
  2. edit에서 원하는 states, inputs, horizon, parameters를 적습니다.
  3. generate C에서 코드 생성을 실행합니다.
  4. matlab 창의 명령을 MATLAB에서 실행합니다.
  5. 생성된 파일 중 csolve.mexw64를 함수처럼 부릅니다. 2에서 정한 파라미터를 맞춰 넣습니다.
settings.verbose = 0;
% solution을 출력할지 정하는 설정. 다른 옵션도 있습니다.

LMPC.A = A;
LMPC.B = B;
LMPC.Q = Q;
LMPC.P = P;
LMPC.R = R;
LMPC.x_0 = x0;
LMPC.u_max = u_max;
LMPC.u_min = u_min;

sol = csolve(LMPC, settings);
u_mpc = sol.u{1};  % receding horizon: 첫 입력만 사용
\(P\)는 3강에서 본 terminal cost 행렬입니다. 그냥 \(Q\)를 복사해 넣지 말고, Riccati 해로 두는 편이 안정성 논의와 맞습니다.

qpOASES

같은 QP를 qpOASES에 직접 넣어도 됩니다. 행렬 \(H,g,A,lb,ub\)를 조립하는 노트가 비어 있으니, 지금은 솔버 링크와 “CVXGEN으로 만든 문제와 같은 QP”라는 점만 기억하면 됩니다.
