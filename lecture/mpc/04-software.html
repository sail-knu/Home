MPC를 짤 때 자주 쓰는 도구입니다. 선형이면 QP, 비선형이면 NLP, Tube면 집합 연산이 추가로 필요합니다.

NMPC

ACADO

MATLAB 인터페이스. 임베디드에 쓰기 좋습니다.

acados

ACADO 후속. 더 빠르다고 하지만 ACADO도 실무에서 충분한 경우가 많습니다.

CasADi

Interior-point (IPOPT). 스케일이 큰 문제, 시스템 식별처럼 데이터가 많을 때. ACADO보다 커스터마이즈가 쉽습니다.

비볼록 문제의 계산 시간 비교는 Robin Verschueren et al., “acados—a modular open-source framework for fast embedded optimal control,” Mathematical Programming Computation, 2022를 보면 됩니다.

LMPC

CVX

MATLAB convex optimization. Gurobi, MOSEK 등을 붙일 수 있습니다.

CVXPY

Python용 convex optimization.

CVXGEN

Convex 문제용 코드 생성. 다음 노트에서 절차를 봅니다.

qpOASES, quadprog, …

QP solver. 문제 크기가 작으면 이것만으로도 충분합니다.

2차원 toy example에서 본 속도 순서는 대략 다음과 같습니다.

qpSWIFT > CVXGEN > qpOASES >> quadprog

Reachability · Tube MPC

CORA

Zonotope 연산. Tube의 RPI set을 구할 때 썼습니다.

MPT3

집합·불변집합 계산에 가장 자주 씁니다.

관련 알고리즘은 active set, interior point, SQP입니다. 논문으로 보면 CasADi (Andersson 2019), ACADO (Houska 2011), CVXGEN (Mattingley 2012)이 출발점으로 좋습니다.
