LPF 주파수 응답 — 무엇이 통과하고 무엇이 잘리나

Δt = 0.01 s로 샘플링한 사인파를 LPF에 통과시킵니다. α와 입력 주파수 f를 움직여 출력 진폭(이득)이 어떻게 변하는지 보세요.

LPF x̄k = α · x̄k−1 + (1 − α) · xk  ·  이득 = 출력 진폭 / 입력 진폭  ·  차단 주파수 fc ≈ (1 − α) / (2π·α·Δt)
