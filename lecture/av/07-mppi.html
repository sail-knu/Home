CBF(6강)는 “이 부등식은 지켜라”는 제약입니다. MPPI는 여러 미래 궤적을 뽑아 싼 쪽을 평균하는 샘플링 MPC입니다. 장애물은 비용(패널티)이라서, 가중치가 작으면 스칠 수 있습니다. 이번 주 데모는 waypoint 없이 목표와 원 장애물만 보고 갑니다.

제어 시퀀스 \(U=(u_0,\ldots,u_{N-1})\), \(u=(v,\omega)\) 주변에 노이즈를 \(K\)개 뿌립니다. 각 샘플을 \(N\)스텝 굴려 비용 \(S_k\)를 센 다음, 싼 샘플에 큰 가중치를 줘 \(U\)를 갱신합니다. 맨 앞 입력만 넣고 \(U\)는 한 칸 당깁니다.

\[ u_k^{(i)}=U+\varepsilon_k,\quad \varepsilon_k\sim\mathcal N(0,\Sigma) \] \[ w_k \propto \exp(-S_k/\lambda),\qquad U\leftarrow\sum_k w_k\,(U+\varepsilon_k) \]

\(\lambda\)(temperature)가 작을수록 제일 싼 샘플만 살아남습니다. 하나를 argmin으로 고르지 않는 것이 핵심입니다.

  • Dynamics — _rollout의 update는 3강 unicycle과 같습니다.
  • Cost — 목표 거리 w_goal, 장애물 w_obs, 속도·조향 패널티. waypoint tracking 항은 없습니다.
  • Sampling — K가 많으면 평균이 안정적이고, N이 길면 앞쪽 장애물을 일찍 봅니다. 기본 \(K=60\), \(N=60\), \(dt=0.15\).
--surprise는 숨은 장애물을 켭니다. w_obs가 커지면 더 일찍 돕니다. 코드의 # 미션 1/2/3 주석을 따라가면 됩니다.

실행

python 07_mppi/run.py
python 07_mppi/run.py --K 30
python 07_mppi/run.py --K 120 --N 80
python 07_mppi/run.py --surprise --w-obs 20
