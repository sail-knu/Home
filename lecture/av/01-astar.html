격자 맵에서 시작점 → 목표의 최단 경로를 찾습니다. open list를 처음부터 짜지 않고, 탐색이 펼쳐지는 화면과 heuristic이 어디 있는지만 보면 됩니다.

알고리즘

A*는 그래프 위 최선 우선 탐색입니다. 이 코드에서 그래프는 격자입니다. 장애물 칸은 막고, 나머지는 8방향으로 이동합니다. 각 칸 \(n\)에 세 값을 둡니다.

  • \(g(n)\): 시작점에서 지금까지 온 실제 비용
  • \(h(n)\): 목표까지 남은 비용의 추정(heuristic)
  • \(f(n)=g(n)+h(n)\): 이 칸을 거쳐 가면 전체가 이 정도일 것이라는 점수

매 스텝에서 \(f\)가 가장 작은 칸을 꺼냅니다. 목표가 나오면 parent를 거슬러 경로를 복원합니다. \(h(n)\)은 calc_heuristic입니다.

Heuristic

\(h\)가 실제 남은 비용보다 작거나 같으면(admissible) A*는 최단 경로를 보장합니다. --weight \(w>1\)이면 \(f=g+w\,h\)인 weighted A*입니다.

--heuristic\(h\)느낌
euclidean\(\sqrt{\Delta x^2+\Delta y^2}\)기본. 8방향과 잘 맞음
manhattan\(|\Delta x|+|\Delta y|\)펼치는 모양이 달라짐
zero\(0\)Dijkstra. 더 많이 펼침
원은 로봇 반지름만큼 팽창한 뒤 격자 칸을 막습니다. 맵은 shared/world.py의 default_world()입니다.

실행

python 01_astar/run.py
python 01_astar/run.py --heuristic manhattan
python 01_astar/run.py --heuristic zero
python 01_astar/run.py --weight 2.0
