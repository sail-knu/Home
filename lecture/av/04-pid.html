이미 채워 둔 heading PID에 게인을 넣어 waypoint를 따라갑니다. 차는 3강 unicycle이고, 선속도 \(v\)는 거의 상수입니다. PID가 만드는 것은 각속도 \(\omega\)입니다.

waypoint → desired heading → heading error → PID → ω → vehicle
\[ \theta_{\mathrm{ref}}=\operatorname{atan2}(y_w-y,\; x_w-x),\qquad e=\operatorname{wrap}(\theta_{\mathrm{ref}}-\theta) \] \[ \omega = K_p e + K_i \int e\,dt + K_d \dot e \]

wrap은 arctan2(sin e, cos e)로 \([-\pi,\pi]\)에 접습니다. 기본값은 P+D입니다 (\(K_p=2.5\), \(K_i=0\), \(K_d=0.15\)).

항하는 일너무 크면
P지금 틀린 만큼 조향코너에서 흔들림, overshoot
I남는 치우침을 누적적분 와인드업. 이 데모는 0이어도 충분
D오차 변화 속도를 감쇠이산 미분 잡음에 민감
도착 반경 안에 들어오면 다음 waypoint로 넘깁니다. 지금 점은 도착할 점만 조준합니다. 점 간격이 오차 스케일을 바꾸는 이야기는 5강 LOS에서 비교합니다. 선택 로직은 shared/tracking.py의 advance_waypoint_index입니다.

python 04_pid_tracking/run.py
python 04_pid_tracking/run.py --kp 3.0 --kd 0.0
python 04_pid_tracking/test_pid.py
