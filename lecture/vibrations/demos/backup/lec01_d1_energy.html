에너지 교환 진동기

질량이 오갈 때 위치에너지 PE ↔ 운동에너지 KE 가 서로를 채우는 과정을 막대와 그래프로 봅니다. 감쇠 c 를 올리면 총에너지가 어디로 새는지도 함께 보입니다.

위치에너지 PE = ½kx² 운동에너지 KE = ½mv² 총에너지 E = PE + KE 속도 v 방향
• 양 끝점(속도 0)에서 PE 최대·KE 0, 평형 통과 순간 KE 최대·PE 0 — 두 막대가 번갈아 찹니다.
• c = 0 이면 아래 그래프의 총에너지 선이 수평 — 에너지가 보존되어 영원히 진동합니다.
• 감쇠를 주면 총에너지가 열로 새어 나가 선이 내려가고 진폭이 줄어듭니다.
• k 를 4배(15 → 60)로 키우면 fₙ 은 2배 — 진폭은 그대로, 리듬만 빨라집니다.

프리셋

복습 미션 — c=0 에서 총에너지 선이 수평인지 확인하고, k=15 → k=60 으로 강성을 4배 올려 fₙ 이 2배가 되는지 보세요.
